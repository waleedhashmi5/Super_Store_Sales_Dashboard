# Super_Store_Sales_Dashboard
An interactive sales analytics dashboard developed 
using Microsoft Power BI to visualize sales, profit, customer segments, and regional performance.
The project utilizes DAX queries, KPI reporting, and dynamic visualizations
to generate business insights and support data-driven decision making.
🚀 Features

* Interactive dashboard with regional filters
* Monthly sales and profit trend analysis
* Sales breakdown by category and sub-category
* Segment-wise and payment mode analysis
* KPI cards for total sales and profit
* Dynamic and user-friendly visualizations

⸻

🛠️ Tools & Technologies

* Microsoft Power BI
* DAX Queries
* Data Visualization
* Data Cleaning & Transformation

⸻

📈 Dashboard Insights

* Consumer segment contributed the highest sales
* COD was the most used payment method
* Technology category generated strong revenue
* Sales and profit showed growth toward year-end
